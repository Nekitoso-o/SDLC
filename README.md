## Дисциплина
Жизненный цикл разработки программного обеспечения

## Описание проекта
Данный репозиторий предназначен для проектирования и разработки программного проекта в рамках изучения жизненного цикла разработки программного обеспечения.

В репозитории будет размещаться исходный код, необходимые заголовочные файлы, документация и другие материалы проекта.

## Структура проекта
- `src/` — исходный код программы.
- `include/` — заголовочные файлы.
- `.gitignore` — правила исключения временных и сборочных файлов.
- `README.md` — описание проекта.
